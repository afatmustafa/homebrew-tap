# afatmustafa/tap

Homebrew tap for [Swapbar](https://github.com/afatmustafa/swapbar), a macOS menu bar app for [claude-swap](https://github.com/realiti4/claude-swap).

```sh
brew install --cask afatmustafa/tap/swapbar
```

Update with `brew upgrade --cask swapbar`. The cask is updated automatically by Swapbar's release workflow.
